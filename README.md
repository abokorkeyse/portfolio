# Abokor Tech - Official Portfolio Website

[![Deploy to GitHub Pages](https://github.com/abokorkeyse/portfolio/actions/workflows/deploy.yml/badge.svg)](https://github.com/abokorkeyse/portfolio/actions/workflows/deploy.yml)

Professional portfolio website for **Abokor Keyse (Abokor Tech)** — Full Stack Developer, Cloud Solutions Specialist, and UI/UX Designer.

## 🚀 Live Demo
- **GitHub Pages:** [https://abokorkeyse.github.io/portfolio/](https://abokorkeyse.github.io/portfolio/)
- **Custom Domain:** [https://abokor.shop/](https://abokor.shop/)

## 🛠 Tech Stack
- **Frontend:** Semantic HTML5, Modern CSS3 (Cyber Tech Orange `#FB5800` & Dark Theme `#1A1A1A`), Vanilla JavaScript (ES6+)
- **3D & Visuals:** Three.js (Holographic Icosahedron & particle galaxy), AOS animations, Typed.js
- **PWA:** Service Worker offline caching (`sw.js`), Web App Manifest
- **CI/CD:** Automated testing and continuous deployment via **GitHub Actions** to **GitHub Pages**

## 🔄 CI/CD Pipeline
Every push to the `main` branch triggers an automated GitHub Actions workflow:
1. **Verify (CI):** Validates all essential web assets and file structures.
2. **Deploy (CD):** Packages and automatically deploys the website to GitHub Pages.
